Test if a socket address is a global unicast address.

This function isn't provided by the system on Unix/Linux platforms as member of the IN6_IS_ADDR test macros. On Microsoft Windows it replaces the imprecise corresponding system function. There it does not check the current specified range for global unicast addresses but only the wide range reservation for future use.

◆ IN6_IS_ADDR_LINKLOCAL2()

bool UPnPsdk::IN6_IS_ADDR_LINKLOCAL2 ( const in6_addr *  a_addr)
inline

Test if a socket address is a link-local address.

The IN6_IS_ADDR_LINKLOCAL test as member of the IN6_IS_ADDR test macros on all supported platforms is weak. They do not check that no subnet is specified. BSD-based operating systems (including macOS) also support an alternative, non-standard syntax, where a numeric zone index is encoded in the second 16-bit word of the address. E.g.: [fe80:3::1ff:fe23:4567:890a]. Following the link-local address standard, it is an lla with subnet. That is a contradiction. I do not support this non-standard and use IN6_IS_ADDR_LINKLOCAL2 for tests, that fails on lla with subnet.

Parameters
[in]a_addrPointer to the address structure of a socket address that shall be checked.
