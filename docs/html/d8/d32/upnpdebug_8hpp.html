◆ Upnp_LogLevel

enum Upnp_LogLevel

Upnp_LogLevel.

The user has the option to select 4 different types of debugging levels, see UpnpSetLogLevel(),

Enumerator
UPNP_CRITICAL 

This level will show only those messages which can halt the normal processing of the library, like memory allocation errors.

UPNP_ERROR 

In addition to the previous errors, this will also show recoverable errors.

UPNP_INFO 

In addition to all previous errors, this also displays the other important operational information regarding the working of the library.

UPNP_ALL 

If the user selects All, then the library displays all the debugging information that it has.

UPnPsdk_VIS FILE * UpnpGetDebugFile ( Upnp_LogLevel  DLevel,
Dbg_Module  Module 
)

Check if the module is turned on for debug and returns the file descriptor corresponding to the debug level. .

Returns
nullptr if the module is turned off for debug otherwise returns the right FILE pointer. To just ask if turned on/off you can use:
FILE* ret = UpnpGetDebugFile(static_cast<Upnp_LogLevel>(NULL),
static_cast<Dbg_Module>(NULL));
// (ret == nullptr) -> logging is disabled.
// (ret != nullptr) -> logging is enabled.
// (ret == stderr) -> logging to stderr is enabled.
