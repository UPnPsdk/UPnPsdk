FILE * UpnpGetDebugFile ( Upnp_LogLevel  DLevel,
Dbg_Module  Module 
)

Check if the module is turned on for debug and returns the file descriptor corresponding to the debug level. .

Returns
nullptr if the module is turned off for debug otherwise returns the right FILE pointer. To just ask if turned on/off you can use:
FILE* ret = UpnpGetDebugFile(static_cast<Upnp_LogLevel>(NULL),
static_cast<Dbg_Module>(NULL));
// (ret == nullptr) -> logging is disabled.
// (ret != nullptr) -> logging is enabled.
// (ret == stderr) -> logging to stderr is enabled.
